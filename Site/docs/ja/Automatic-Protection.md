# 自動保護

ユーザーがしきい値に達すると、**設定 → 自動保護** で有効にした操作が実行されます。ローカルの操作を先に行い、API 呼び出しは VRChat の制限に合わせて順番に並びます。

## 操作

| 操作 | OSC が必要 | 内容 |
| --- | --- | --- |
| VRChat を終了 | いいえ | クライアントを正常終了させるので、退出パケットも送られます。 |
| セーフモード (OSC) | はい | パニックボタンを押し、フレンド以外のアバターをまとめて置き換えます。 |
| アバターを切り替え (OSC) | はい | 設定のアバター ID に切り替えるよう要求します。 |
| ユーザーをブロック | いいえ | VRChat API を呼びます。 |
| アバター操作を無効化 | いいえ | VRChat API を呼びます。 |
| チャットボックスを隠す | いいえ | VRChat API を呼びます。 |

## 順番

1. **VRChat を終了** は別タスクで始まり、ほかの処理を止めません。実際に終了した場合は、守るものが残っていないので OSC の操作は省略されます。
2. **OSC**（セーフモード、アバターの切り替え）は API の順番を待たずにすぐ送られます。
3. **API**（ブロック、アバター操作、チャットボックス）は約 3 秒間隔で 1 つずつ実行されます。

## フレンドとホワイトリスト

フレンドはホワイトリストと同じ扱いで、操作の対象になりません。自分のアカウントも採点されません。スコアが高くても何もしないようにしたい場合は、ユーザー ID をホワイトリストに追加してください。

## API の間隔

VRChat はモデレーション要求を数秒に 1 回程度しか受け付けません。AntiBot はその間隔を守り、拒否された要求は操作を捨てずに再試行します。

## 実行されない場合

- ユーザーのスコアがしきい値未満。
- フレンド、ホワイトリスト、または自分のアカウント。
- 同じインスタンスでそのユーザーをすでに処理した。
