# はじめに

AntiBot は VRChat が書き出しているログを読み、インスタンスに誰がいるかを表示し、入ってきたユーザーを採点します。しきい値を超えたら、アバターの読み込みが終わる前に行動できます。

## 必要なもの

- Windows x64。ダウンロードは自己完結なので、.NET ランタイムを入れる必要はありません。
- 同じ PC で VRChat が動作していること。ログを読むので、VRChat がインスタンスにいる間だけ内容が分かります。
- OSC を使う 2 つの操作（セーフモードとアバターの切り替え）には、VRChat で OSC を有効にします。[OSC](OSC) を参照してください。

## 1. サインイン

普段使っている VRChat アカウントでサインインします。VRChat が求めたときにメールコードと 2 段階認証コードを入力します。セッションは Windows Hello か、自分で決めたパスワードで保護できます。

アカウントはプロフィール取得とモデレーションのために VRChat API を呼ぶだけに使います。パスワードは保存しません。

## 2. ログフォルダを指定

既定の場所は次のとおりです。

```
%USERPROFILE%\AppData\LocalLow\VRChat\VRChat
```

AntiBot はそのフォルダの最新の `output_log_*.txt` を追いかけます。MOD もプラグインも改変クライアントも不要です。

## 3. しきい値を決める

しきい値は 0〜100 のスコアです。新しいユーザーは全員採点され、理由がスコアの横に表示されます。しきい値未満では何も起きず、フレンドとホワイトリストのユーザーには何もしません。

スコアの中身は [脅威スコア](Threat-Scoring)、超えた後の動作は [自動保護](Automatic-Protection) を参照してください。

## 4. 操作を選ぶ

**設定 → 自動保護** を開き、必要なものをオンにします。セーフモードとアバターの切り替えには OSC が必要で、それ以外は OSC なしで動きます。
