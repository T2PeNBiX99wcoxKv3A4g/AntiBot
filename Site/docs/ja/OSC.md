# OSC

VRChat の OSC 入力を使うと、ローカルのプログラムからクライアントのボタンを押せます。AntiBot は API ではできない次の 2 つの操作に使います。

- **セーフモード** — フレンド以外のアバターをまとめて置き換えます。
- **アバターの切り替え** — 別のアバターを着るよう VRChat に要求します。

どちらも任意です。ブロック、アバター操作、チャットボックスは OSC なしで動きます。

## VRChat で OSC を有効にする

1. アクションメニューを開きます。
2. **Options → OSC** に進みます。
3. **Enabled** をオンにします。

VRChat はループバックの UDP **9000** 番で待ち受けます。AntiBot は VRChat のログ（`Advertising Service … of type OSC on 9000`）からポートを知るので、OSC が使えるかどうかも判断できます。

## AntiBot で確認する

**設定 → OSC** を開きます。

- **OSC ポート** — VRChat を独自の `--osc` ポートで起動していなければ 9000 です。
- **接続をテスト** — VRChat のクイックメニューを開くメッセージを送ります。メニューが開けば OSC は機能しています。
- ボタンの下の行に、VRChat がこのセッションで OSC ポートを公開したかが表示されます。

ポートは入力すると自動で保存され、テストは保存前でも欄の値を使います。

## AntiBot が送るもの

| アドレス | 用途 |
| --- | --- |
| `/input/PanicButton` | セーフモード |
| `/avatar/change` | アバターの切り替え |

`/input/PanicButton` はセーフモードを**オンにするだけ**で、オフにはなりません。しきい値を超えたユーザーごとに送りますが、すでにオンでも問題ありません。

## 現在のアバターの取得

VRChat は UDP **9001** 番に自身の OSC 出力を送り、アバターを変えるたびに `/avatar/change` を出します。AntiBot はそこを監視しているので、すでに目的のアバターを着ている場合は切り替えを省略できます。

ほかのプログラムが 9001 番を使っている場合でも AntiBot は動作しますが、アバターの判定だけができなくなります。

## セーフモードを切る

セーフモードをオフにする OSC アドレスはありません。アクションメニューの Safety から戻すか、パニックボタンのキー操作をもう一度行ってください。次にしきい値を超えたユーザーが来ると、またオンになります。
