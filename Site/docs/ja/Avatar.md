# アバター

アバターの切り替えは、着ているものを変える唯一の操作です。既定ではオフです。

## アバター ID

VRChat はアバターを `avtr_` で始まる ID で識別します。

```
avtr_4d3c393f-ef70-4468-bb9e-8380f8a43d8f
```

**設定 → 自動保護 → アバターを切り替え (OSC)** に貼り付けます。欄はパスワードと同じように伏せられ、目のボタンで確認できます。

## 切り替えられるアバター

VRChat がサイトを経由せずに着られるアバターだけです。

- **お気に入り**のアバター
- **最近使った**アバター
- **自分でアップロードした**アバター

それ以外は VRChat がエラーも出さずに無視するので、お気に入りに入れていない公開アバターは読み込まれません。

## ID の調べ方

`vrchat.com` のアバターのページを開き、アドレスの `avtr_…` 部分をコピーするか、VRChat の自分のアバター一覧に表示される ID を使ってください。

## しきい値を超えたとき

ユーザーがしきい値を超えると、AntiBot は次を送ります。

```
/avatar/change avtr_…
```

**自動で元には戻しません。** 落ち着いたら自分で戻すか、同じ欄に別の ID を入れて切り替えてください。

## 現在のアバター

AntiBot は VRChat の OSC 出力（UDP 9001）を監視しています。VRChat はアバターが変わるたびに `/avatar/change` を送るので、いま着ているものが分かり、すでに目的のアバターなら要求を省略します。

OSC の有効化とポートの確認は [OSC](OSC) を参照してください。
