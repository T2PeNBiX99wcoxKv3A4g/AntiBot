# 脅威スコア

新しいユーザーは全員スコアが付きます。0 から始まり、**上限はありません**。これは割合ではなくスコアなので、強いシグナルが重なれば 100 を超えます。設定のしきい値で、自動操作を実行するかどうかが決まります。

これは推測であって判定ではありません。本物の人間が高く出ることも、ボットが低く出ることもあります。

> **判別できること・できないこと**
>
> AntiBot は、改造クライアント経由でアバターや音声、プレイヤー情報などを収集する自動 BOT を
> 主な対象にしています。ただし、改造クライアントを使っているのが人間の場合、見た目や挙動は
> ほとんど同じで、スコアだけでは区別できません。信頼ランクが高いからといって、そのアカウントが
> 人間である保証にもなりません。スコアは断定ではなく、あくまで目安として扱ってください。

スコアは横に表示される理由の合計で、理由ごとに点数があります。緑の理由はスコアを下げ、赤の理由は上げます。

## 名前のパターン

| パターン | 点数 |
| --- | --- |
| 4 文字の 16 進サフィックス（`Blackfir3 ed36`、`Nisarth0alraisth b991`） | +15 |
| 名前に数字が混ざる（`rokun0304`） | +5 |
| 英字と数字が長く続く（`katou230791jp`） | +5 |

2 つの数字パターンはどちらか一方だけが加算されるため、形のボーナスは +5 までです。よくあるボット名（発音できる単語＋数字＋16 進サフィックス）は 20 になります。名前のシグナルは合計 20 で頭打ちなので、名前だけで既定のしきい値には届きません。

## プロフィールの文章

カスタムステータス、代名詞、自己紹介は、句読点を正規化してから照合します。似た文字に置き換えてもすり抜けられません。ドットを `(dot)` や `[dot]`、単語の `dot` と書いても同じで、`hexed (dot) cc` は `hexed.cc` として扱います。

自己紹介は公開プロフィールから取得します。すべてのプレイヤーについて取得し、更新は 10 分に 1 回までです。一括操作ページと詳細パネルでは常に読み込みます。

| 文章 | 点数 |
| --- | --- |
| 不審な言い回し（`hexed`、`oversee`、`quality cheats`、`user stalking`、`tracking`、`4 free` など） | +5 |
| `hexed` | +10 |
| `check bio` | +5 |
| `hexed.cc` | +110 |
| `oversee` | +10 |
| `oversee.lol` | +110 |

## プラットフォーム

Quest と iOS でボットが動くことはまずないため、その場合は残りのスコアが半分になります。

## フレンドとホワイトリスト

フレンドはホワイトリストと同じ扱いで、採点も操作もされません。自分のアカウントも採点されません。
