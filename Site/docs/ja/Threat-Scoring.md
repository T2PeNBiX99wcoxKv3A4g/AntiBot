# 脅威スコア

新しいユーザーは全員スコアが付きます。0 から始まり、**上限はありません**。強いシグナルが重なれば 100 を超えます。設定のしきい値は 0〜100 なので、100 を超えたスコアは必ずしきい値を超えます。

これは推測であって判定ではありません。本物の人間が高く出ることも、ボットが低く出ることもあります。

> **判別できること・できないこと**
>
> AntiBot は、改造クライアント経由でアバターや音声、プレイヤー情報などを収集する自動 BOT を
> 主な対象にしています。ただし、改造クライアントを使っているのが人間の場合、見た目や挙動は
> ほとんど同じで、スコアだけでは区別できません。信頼ランクが高いからといって、そのアカウントが
> 人間である保証にもなりません。スコアは断定ではなく、あくまで目安として扱ってください。

スコアは横に表示される理由の合計で、理由ごとに点数があります。緑の理由はスコアを下げ、赤の理由は上げます。

## 名前のパターン

| パターン | 点数 |
| --- | --- |
| 4 文字の 16 進サフィックス（`Blackfir3 ed36`） | +10 |
| 名前に数字が混ざる（`rokun0304`） | +10 |
| 英字と数字が長く続く（`katou230791jp`） | +20 |

名前のシグナルは合計 40 で頭打ちなので、名前だけで既定のしきい値には届きません。

## プロフィールの文章

カスタムステータス、代名詞、自己紹介は、句読点を正規化してから照合します。似た文字に置き換えてもすり抜けられません。

| 文章 | 点数 |
| --- | --- |
| 不審な言い回し（`hexed`、`banned`、`collect avatars` など） | +5 |
| `hexed` | +10 |
| `check bio` | +5 |
| `hexed.cc` | +100 |

## プラットフォーム

Quest と iOS でボットが動くことはまずないため、その場合は残りのスコアが半分になります。

## フレンドとホワイトリスト

フレンドはホワイトリストと同じ扱いで、採点も操作もされません。自分のアカウントも採点されません。
