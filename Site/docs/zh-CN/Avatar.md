# 头像

切换头像是唯一会改变你外观的操作，默认关闭。

## 头像 ID

VRChat 用 `avtr_` 开头的 ID 标识头像，例如：

```
avtr_4d3c393f-ef70-4468-bb9e-8380f8a43d8f
```

把它粘贴到 **设置 → 自动保护 → 切换头像**。输入框像密码一样被遮住，点眼睛按钮可以确认内容。

## 可以切换到哪些头像

只有 VRChat 允许你不经过网站就能穿上的头像：

- **收藏**里的头像
- **最近使用**的头像
- **自己上传**的头像

其他头像会被 VRChat 直接忽略，也不会报错，所以没有收藏的公开头像不会加载。

## 在哪里找 ID

打开 `vrchat.com` 上该头像的页面，复制地址里的 `avtr_…` 部分，或者使用 VRChat 中自己头像列表显示的 ID。

## 触发时会发生什么

用户超过阈值时，AntiBot 会发送：

```
/avatar/change avtr_…
```

它**不会自动换回**。等实例安静下来后自己换回来，或者在同一栏填另一个 ID。

## 当前头像

AntiBot 监听 VRChat 的 OSC 输出（UDP 9001）。VRChat 每次换头像都会发送 `/avatar/change`，所以 AntiBot 知道你穿着什么，已经是目标头像时就不会重复请求。

启用 OSC 和确认端口见 [OSC](OSC)。
