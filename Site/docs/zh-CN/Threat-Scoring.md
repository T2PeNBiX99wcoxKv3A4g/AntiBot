# 威胁评分

每个新用户都会得到一个分数。它从 0 开始，**没有上限**：几个强信号叠加就能超过 100。设置里的阈值是 0–100，所以超过 100 的分数一定会触发。

这只是猜测，不是判定：真人可能分很高，机器人也可能分很低。

> **能分辨什么、不能分辨什么**
>
> AntiBot 主要针对通过改造客户端自动收集资料（头像、语音、玩家信息等）的机器人。但如果使用改造
> 客户端的是真人，外观和行为几乎无法区分，单靠分数无法可靠判断。信任等级高也不代表这个账号一定
> 是真人，请把分数当作提示，而不是判定。

分数是旁边列出的原因之和，每个原因都有自己的分值。绿色的原因会降低分数，红色的会提高。

## 账号年龄

| 账号创建时间 | 分数 |
| --- | --- |
| 少于 7 天 | +40 |
| 少于 30 天 | +35 |
| 少于 90 天 | +25 |
| 少于 180 天 | +15 |
| 少于 1 年 | +8 |
| 1–2 年 | 0 |
| 2–3 年 | −10 |
| 3–4 年 | −20 |
| 4–5 年 | −30 |
| 5 年或更久 | −40 |

## 信任等级

| User | 0 |
| New User | +10 |

| Nuisance | +60 |

## 名字模式

| 模式 | 分数 |
| --- | --- |
| 四位十六进制后缀（`Blackfir3 ed36`、`Nisarth0alraisth b991`） | +15 |
| 名字里混入数字（`rokun0304`） | +5 |
| 很长的字母数字交替（`katou230791jp`） | +5 |

两种数字模式只会加其中一个，所以形态奖励最多 +5。常见的机器人名字（可读单词＋数字＋十六进制后缀）会得到 20 分。名字相关的分数合计最多 20，所以单靠名字到不了默认阈值。

## 个人资料文字

自定义状态、代词和简介会先把标点归一化再匹配，用相似的字符也绕不过去。

简介来自公开资料。AntiBot 会为每位玩家获取，最多每十分钟刷新一次；批量操作页面和详情面板则始终加载。

| 文字 | 分数 |
| --- | --- |
| 可疑措辞（`hexed`、`oversee`、`quality cheats`、`user stalking`、`tracking`、`4 free` 等） | +5 |
| `hexed` | +10 |
| `check bio` | +5 |
| `hexed.cc` | +100 |
| `oversee` | +10 |
| `oversee.lol` | +100 |

## 平台

Quest 和 iOS 上几乎不可能运行机器人，所以这些平台的其他分数会减半。

## 好友和白名单

好友按白名单处理，既不评分也不处理。你自己的账号也不会被评分。
