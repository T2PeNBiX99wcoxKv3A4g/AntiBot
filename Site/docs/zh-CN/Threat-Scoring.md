# 威胁评分

每个新用户都会得到一个分数。它从 0 开始，**没有上限**：几个强信号叠加就能超过 100。设置里的阈值是 0–100，所以超过 100 的分数一定会触发。

这只是猜测，不是判定：真人可能分很高，机器人也可能分很低。

分数是旁边列出的原因之和，每个原因都有自己的分值。绿色的原因会降低分数，红色的会提高。

## 账号年龄

| 账号创建时间 | 分数 |
| --- | --- |
| 少于 7 天 | +40 |
| 少于 30 天 | +35 |
| 少于 90 天 | +25 |
| 少于 180 天 | +15 |
| 少于 1 年 | +8 |
| 少于 2 年 | +3 |
| 2 年或更久 | 0 |

## 信任等级

`User` 是中间值。

| 等级 | 分数 |
| --- | --- |
| Trusted User | −10 |
| Known User | −5 |
| User | 0 |
| New User | +10 |
| Visitor | +30 |
| probably Nuisance | +30 |
| Nuisance | +60 |

## 名字模式

| 模式 | 分数 |
| --- | --- |
| 四位十六进制后缀（`Blackfir3 ed36`） | +10 |
| 名字里混入数字（`rokun0304`） | +10 |
| 很长的字母数字交替（`katou230791jp`） | +20 |

名字相关的分数合计最多 40，所以单靠名字到不了默认阈值。

## 个人资料文字

自定义状态、代词和简介会先把标点归一化再匹配，用相似的字符也绕不过去。

| 文字 | 分数 |
| --- | --- |
| 可疑措辞（`hexed`、`banned`、`collect avatars` 等） | +5 |
| `hexed` | +10 |
| `check bio` | +5 |
| `hexed.cc` | +100 |

## 头像

| 头像 | 分数 |
| --- | --- |
| 名字叫「Sex Bot」 | +10 |
| VRChat 默认的 Robot 头像 | +5 |

## 平台

Quest 和 iOS 上几乎不可能运行机器人，所以这些平台的其他分数会减半。

## 好友和白名单

好友按白名单处理，既不评分也不处理。你自己的账号也不会被评分。
