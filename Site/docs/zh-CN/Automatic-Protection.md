# 自动保护

用户达到阈值时，AntiBot 会执行你在 **设置 → 自动保护** 中开启的操作。本地操作先执行，因为它们不需要服务器；API 调用则按 VRChat 的限制排队。

## 操作

| 操作 | 需要 OSC | 作用 |
| --- | --- | --- |
| 关闭 VRChat | 否 | 正常退出客户端，离开封包仍会发送。 |
| 安全模式 (OSC) | 是 | 按下 VRChat 的紧急按钮，一次性替换所有非好友的头像。 |
| 切换头像 (OSC) | 是 | 要求 VRChat 换上设置中的头像 ID。 |
| 屏蔽用户 | 否 | 调用 VRChat API。 |
| 关闭头像交互 | 否 | 调用 VRChat API。 |
| 隐藏聊天框 | 否 | 调用 VRChat API。 |

## 顺序

1. **关闭 VRChat** 在独立任务中开始，不会卡住其他操作。如果客户端真的退出了，OSC 操作会被跳过，因为已经没有需要保护的东西。
2. **OSC**（安全模式、切换头像）立即发送，不等 API 队列。
3. **API**（屏蔽、头像交互、聊天框）一次一个，间隔约 3 秒。

## 好友和白名单

好友按白名单处理，永远不会被处理。你自己的账号也不会被评分。想让某个用户即使分数很高也不被处理，就把他的用户 ID 加入白名单。

## API 节奏

VRChat 大约每几秒才接受一次管理请求。AntiBot 会遵守这个节奏，被拒绝的请求会重试，而不是直接丢掉。

## 什么时候不会执行

- 用户分数低于阈值。
- 用户是好友、在白名单里，或者就是你自己。
- 这个实例里已经处理过该用户。
