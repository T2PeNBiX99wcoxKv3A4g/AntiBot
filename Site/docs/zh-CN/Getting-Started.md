# 开始使用

AntiBot 读取 VRChat 自己写出的日志，显示实例里有谁，并给每个进入的用户打分。超过阈值时，它能在对方的头像加载完成之前行动。

## 需要什么

- Windows x64。下载的是自包含版本，不需要另外安装 .NET 运行时。
- 同一台电脑上运行着 VRChat。AntiBot 读取它的日志，所以只有在 VRChat 进入实例后才知道里面的情况。
- 两个需要 OSC 的操作（安全模式和切换头像）要在 VRChat 中启用 OSC，见 [OSC](OSC)。

## 1. 登录

用你平时玩 VRChat 的账号登录。VRChat 要求时，AntiBot 会询问邮箱验证码和两步验证码；会话可以用 Windows Hello 或你自定的密码保护。

账号只用于调用 VRChat API 获取资料和执行管理操作，密码不会被保存。

## 2. 指定日志文件夹

默认位置是：

```
%USERPROFILE%\AppData\LocalLow\VRChat\VRChat
```

AntiBot 会跟随该文件夹中最新的 `output_log_*.txt`。不需要模组、插件或修改过的客户端。

## 3. 设定阈值

阈值是 0 到 100 的分数。每个新用户都会被评分，原因显示在分数旁边。低于阈值时什么都不会发生，好友和白名单用户永远不会被处理。

分数的构成见 [威胁评分](Threat-Scoring)，超过阈值后的动作见 [自动保护](Automatic-Protection)。

## 4. 选择操作

打开 **设置 → 自动保护**，开启你需要的操作。安全模式和切换头像需要 OSC，其他操作不需要。
