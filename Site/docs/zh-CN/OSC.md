# OSC

VRChat 的 OSC 输入可以让本地程序按下客户端里的按钮。AntiBot 用它来做 API 做不到的两件事：

- **安全模式** — 一次性替换所有非好友的头像。
- **切换头像** — 要求 VRChat 换上另一个头像。

两者都是可选的。屏蔽、头像交互和聊天框都不需要 OSC。

## 在 VRChat 中启用 OSC

1. 打开快捷菜单。
2. 进入 **Options → OSC**。
3. 把 **Enabled** 打开。

VRChat 随后在本机 UDP **9000** 端口监听。AntiBot 从 VRChat 的日志（`Advertising Service … of type OSC on 9000`）里得知端口，因此也能判断 OSC 是否可用。

## 在 AntiBot 中确认

打开 **设置 → OSC**：

- **OSC 端口** — 除非 VRChat 用自定义的 `--osc` 端口启动，否则是 9000。
- **测试连接** — 发送一条会打开 VRChat 快捷菜单的消息。菜单打开就说明 OSC 正常。
- 按钮下面那一行会显示 VRChat 这次会话有没有公开 OSC 端口。

端口在输入时自动保存，测试会使用输入框里的值，即使还没保存。

## AntiBot 发送的内容

| 地址 | 用途 |
| --- | --- |
| `/input/PanicButton` | 安全模式 |
| `/avatar/change` | 切换头像 |

`/input/PanicButton` 只会把安全模式**打开**，不会关闭它。每个超过阈值的用户都会触发一次，已经打开时也不会有副作用。

## 如何知道当前头像

VRChat 会把自身的 OSC 输出发到 UDP **9001**，每次换头像都会发出 `/avatar/change`。AntiBot 监听这个端口，因此已经穿着目标头像时会跳过切换。

如果 9001 端口已被其他程序占用，AntiBot 仍然可用，只是无法判断当前头像。

## 关闭安全模式

没有可以通过 OSC 关闭安全模式的地址。请在快捷菜单的 Safety 里改回来，或者再按一次紧急按钮的按键组合。下一个超过阈值的用户到来时，它又会被打开。
