# 威脅評分

每個新使用者都會得到一個分數。它從 0 開始，**沒有上限**：幾個強訊號疊加就能超過 100。設定裡的閾值是 0–100，所以超過 100 的分數一定會觸發。

這只是猜測，不是判定：真人可能分很高，機器人也可能分很低。

分數是旁邊列出的原因之和，每個原因都有自己的分值。綠色的原因會降低分數，紅色的會提高。

## 帳號年齡

| 帳號建立時間 | 分數 |
| --- | --- |
| 少於 7 天 | +40 |
| 少於 30 天 | +35 |
| 少於 90 天 | +25 |
| 少於 180 天 | +15 |
| 少於 1 年 | +8 |
| 少於 2 年 | +3 |
| 2 年或更久 | 0 |

## 信任等級

`User` 是中間值。

| 等級 | 分數 |
| --- | --- |
| Trusted User | −10 |
| Known User | −5 |
| User | 0 |
| New User | +10 |
| Visitor | +30 |
| probably Nuisance | +30 |
| Nuisance | +60 |

## 名稱模式

| 模式 | 分數 |
| --- | --- |
| 四位十六進位後綴（`Blackfir3 ed36`） | +10 |
| 名稱裡混入數字（`rokun0304`） | +10 |
| 很長的字母數字交替（`katou230791jp`） | +20 |

名稱相關的分數合計最多 40，所以單靠名稱到不了預設閾值。

## 個人資料文字

自訂狀態、代名詞和簡介會先把標點正規化再比對，用相似的字元也繞不過去。

| 文字 | 分數 |
| --- | --- |
| 可疑措辭（`hexed`、`banned`、`collect avatars` 等） | +5 |
| `hexed` | +10 |
| `check bio` | +5 |
| `hexed.cc` | +100 |

## 頭像

| 頭像 | 分數 |
| --- | --- |
| 名稱叫「Sex Bot」 | +10 |
| VRChat 預設的 Robot 頭像 | +5 |

## 平台

Quest 和 iOS 上幾乎不可能執行機器人，所以這些平台的其他分數會減半。

## 好友和白名單

好友依白名單處理，既不評分也不處理。你自己的帳號也不會被評分。
