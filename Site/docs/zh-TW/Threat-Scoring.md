# 威脅評分

每個新使用者都會得到一個分數。它從 0 開始，**沒有上限**：幾個強訊號疊加就能超過 100。設定裡的閾值是 0–100，所以超過 100 的分數一定會觸發。

這只是猜測，不是判定：真人可能分很高，機器人也可能分很低。

> **能分辨什麼、不能分辨什麼**
>
> AntiBot 主要針對透過改造客戶端自動收集資料（頭像、語音、玩家資訊等）的機器人。但如果使用改造
> 客戶端的是真人，外觀與行為幾乎無法區分，單靠分數無法可靠判斷。信任等級高也不代表這個帳號一定
> 是真人，請把分數當作提示，而不是判定。

分數是旁邊列出的原因之和，每個原因都有自己的分值。綠色的原因會降低分數，紅色的會提高。

## 帳號年齡

| 帳號建立時間 | 分數 |
| --- | --- |
| 少於 7 天 | +40 |
| 少於 30 天 | +35 |
| 少於 90 天 | +25 |
| 少於 180 天 | +15 |
| 少於 1 年 | +8 |
| 1–2 年 | 0 |
| 2–3 年 | −10 |
| 3–4 年 | −20 |
| 4–5 年 | −30 |
| 5 年或更久 | −40 |

## 信任等級

| 等級 | 分數 |

| Trusted User | −10 |
| Known User | −5 |
| User | 0 |
| New User | +10 |
| Visitor | +30 |
| probably Nuisance | +30 |
| Nuisance | +60 |

## 名稱模式

| 模式 | 分數 |
| --- | --- |
| 四位十六進位後綴（`Blackfir3 ed36`） | +10 |
| 名稱裡混入數字（`rokun0304`） | +10 |
| 很長的字母數字交替（`katou230791jp`） | +20 |

名稱相關的分數合計最多 40，所以單靠名稱到不了預設閾值。

## 個人資料文字

自訂狀態、代名詞和簡介會先把標點正規化再比對，用相似的字元也繞不過去。

簡介來自公開資料。AntiBot 會為每位玩家取得，最多每十分鐘重新整理一次；批次操作頁面和詳細面板則一律載入。

| 文字 | 分數 |
| --- | --- |
| 可疑措辭（`hexed`、`oversee`、`quality cheats`、`user stalking`、`tracking`、`4 free` 等） | +5 |
| `hexed` | +10 |
| `check bio` | +5 |
| `hexed.cc` | +100 |
| `oversee` | +10 |
| `oversee.lol` | +100 |

## 平台

Quest 和 iOS 上幾乎不可能執行機器人，所以這些平台的其他分數會減半。

## 好友和白名單

好友依白名單處理，既不評分也不處理。你自己的帳號也不會被評分。
