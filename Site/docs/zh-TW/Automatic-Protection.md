# 自動保護

使用者達到閾值時，AntiBot 會執行你在 **設定 → 自動保護** 中開啟的操作。本機操作先執行，因為它們不需要伺服器；API 呼叫則依 VRChat 的限制排隊。

## 操作

| 操作 | 需要 OSC | 作用 |
| --- | --- | --- |
| 關閉 VRChat | 否 | 正常結束客戶端，離開封包仍會送出。 |
| 安全模式 | 是 | 按下 VRChat 的緊急按鈕，一次替換所有非好友的頭像。 |
| 切換頭像 | 是 | 要求 VRChat 換上設定中的頭像 ID。 |
| 封鎖使用者 | 否 | 呼叫 VRChat API。 |
| 關閉頭像互動 | 否 | 呼叫 VRChat API。 |
| 隱藏聊天框 | 否 | 呼叫 VRChat API。 |

## 順序

1. **關閉 VRChat** 在獨立工作中開始，不會卡住其他操作。如果客戶端真的結束了，OSC 操作會被跳過，因為已經沒有需要保護的東西。
2. **OSC**（安全模式、切換頭像）立即送出，不等 API 佇列。
3. **API**（封鎖、頭像互動、聊天框）一次一個，間隔約 3 秒。

## 好友和白名單

好友依白名單處理，永遠不會被處理。你自己的帳號也不會被評分。想讓某個使用者即使分數很高也不被處理，就把他的使用者 ID 加入白名單。

## API 節奏

VRChat 大約每幾秒才接受一次管理要求。AntiBot 會遵守這個節奏，被拒絕的要求會重試，而不是直接丟掉。

## 什麼時候不會執行

- 使用者分數低於閾值。
- 使用者是好友、在白名單裡，或者就是你自己。
- 這個實例裡已經處理過該使用者。
