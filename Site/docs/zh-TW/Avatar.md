# 頭像

切換頭像是唯一會改變你外觀的操作，預設關閉。

## 頭像 ID

VRChat 用 `avtr_` 開頭的 ID 標識頭像，例如：

```
avtr_4d3c393f-ef70-4468-bb9e-8380f8a43d8f
```

把它貼到 **設定 → 自動保護 → 切換頭像**。欄位像密碼一樣被遮住，點眼睛按鈕可以確認內容。

## 可以切換到哪些頭像

只有 VRChat 允許你不經過網站就能穿上的頭像：

- **收藏**裡的頭像
- **最近使用**的頭像
- **自己上傳**的頭像

其他頭像會被 VRChat 直接忽略，也不會報錯，所以沒有收藏的公開頭像不會載入。

## 在哪裡找 ID

開啟 `vrchat.com` 上該頭像的頁面，複製網址裡的 `avtr_…` 部分，或使用 VRChat 中自己頭像清單顯示的 ID。

## 觸發時會發生什麼

使用者超過閾值時，AntiBot 會送出：

```
/avatar/change avtr_…
```

它**不會自動換回**。等實例安靜下來後自己換回來，或在同一欄填另一個 ID。

## 目前頭像

AntiBot 監聽 VRChat 的 OSC 輸出（UDP 9001）。VRChat 每次換頭像都會送出 `/avatar/change`，所以 AntiBot 知道你穿著什麼，已經是目標頭像時就不會重複要求。

啟用 OSC 和確認連接埠見 [OSC](OSC)。
