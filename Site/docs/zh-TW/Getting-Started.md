# 開始使用

AntiBot 讀取 VRChat 自己寫出的日誌，顯示實例裡有誰，並替每個進入的使用者評分。超過閾值時，它能在對方的頭像載入完成之前行動。

## 需要什麼

- Windows 或 Linux，x64。下載的是自包含版本，不需要另外安裝 .NET 執行階段。
- 同一台電腦上執行著 VRChat。AntiBot 讀取它的日誌，所以只有在 VRChat 進入實例後才知道裡面的情況。
- 兩個需要 OSC 的操作（安全模式和切換頭像）要在 VRChat 中啟用 OSC，見 [OSC](OSC)。

## 1. 登入

用你平常玩 VRChat 的帳號登入。VRChat 要求時，AntiBot 會詢問電子郵件驗證碼和兩步驟驗證碼；工作階段可以用 Windows Hello 或你自訂的密碼保護。

帳號只用於呼叫 VRChat API 取得資料和執行管理操作，密碼不會被儲存。

## 2. 指定日誌資料夾

預設位置是：

```
%USERPROFILE%\AppData\LocalLow\VRChat\VRChat
```

AntiBot 會跟隨該資料夾中最新的 `output_log_*.txt`。不需要模組、外掛或修改過的客戶端。

## 3. 設定閾值

閾值是 0 到 100 的分數。每個新使用者都會被評分，原因顯示在分數旁邊。低於閾值時什麼都不會發生，好友和白名單使用者永遠不會被處理。

分數的構成見 [威脅評分](Threat-Scoring)，超過閾值後的動作見 [自動保護](Automatic-Protection)。

## 4. 選擇操作

開啟 **設定 → 自動保護**，開啟你需要的操作。安全模式和切換頭像需要 OSC，其他操作不需要。
