# OSC

VRChat 的 OSC 輸入可以讓本機程式按下客戶端裡的按鈕。AntiBot 用它來做 API 做不到的兩件事：

- **安全模式** — 一次替換所有非好友的頭像。
- **切換頭像** — 要求 VRChat 換上另一個頭像。

兩者都是選用的。封鎖、頭像互動和聊天框都不需要 OSC。

## 在 VRChat 中啟用 OSC

1. 開啟快捷選單。
2. 進入 **Options → OSC**。
3. 把 **Enabled** 打開。

VRChat 接著會在本機 UDP **9000** 連接埠監聽。AntiBot 從 VRChat 的日誌（`Advertising Service … of type OSC on 9000`）得知連接埠，因此也能判斷 OSC 是否可用。

## 在 AntiBot 中確認

開啟 **設定 → OSC**：

- **OSC 連接埠** — 除非 VRChat 用自訂的 `--osc` 連接埠啟動，否則會是 9000。
- **測試連線** — 送出一則會開啟 VRChat 快捷選單的訊息。選單開啟就代表 OSC 正常。
- 按鈕下面那一行會顯示 VRChat 這次工作階段有沒有公開 OSC 連接埠。

連接埠在輸入時自動儲存，測試會使用欄位裡的值，即使還沒儲存。

## AntiBot 送出的內容

| 位址 | 用途 |
| --- | --- |
| `/input/PanicButton` | 安全模式 |
| `/avatar/change` | 切換頭像 |

`/input/PanicButton` 只會把安全模式**打開**，不會關閉它。每個超過閾值的使用者都會觸發一次，已經打開時也不會有副作用。

## 如何知道目前頭像

VRChat 會把自身的 OSC 輸出送到 UDP **9001**，每次換頭像都會送出 `/avatar/change`。AntiBot 監聽這個連接埠，因此已經穿著目標頭像時會跳過切換。

如果 9001 連接埠已被其他程式占用，AntiBot 仍然可用，只是無法判斷目前頭像。

## 關閉安全模式

沒有可以透過 OSC 關閉安全模式的位址。請在快捷選單的 Safety 裡改回來，或再按一次緊急按鈕的按鍵組合。下一個超過閾值的使用者到來時，它又會被開啟。
